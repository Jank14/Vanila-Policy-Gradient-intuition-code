What the agent sees

Only these four numbers — no picture. Watch the angular velocity gauge: it moves before the angle does. Good players react to it.

Every step is a forced choice

There is no "do nothing" action. Push left or push right, 50 times a second. In step mode you get as long as you like to decide.

The average is J

Each episode is one sample of the return. The mean over 100 episodes is our estimate of J for that policy — exactly what the notebook's progress bar reports.

Why isn't random ≈ 0?

Even random pushes take ~20 steps to lose the pole: falling takes time. That's the baseline to beat. "Always right" is worse than random — it shoves the cart one way.

The lesson for today

"Angle + velocity" solves it — a policy that uses all of the state. VPG will discover a rule like this on its own, from nothing but +1s.

The experiment

Cart A and cart B start in the same place (same position, or same pole angle). Only their velocity differs. Then both get identical pushes.

Read the chart

Position (or angle) over time for both carts. If that one number were "the state", the two lines would have to stay together. They don't: the velocity was needed too.

Why this matters for RL

The policy only sees the state. If the state were missing the velocity, the best action would be ambiguous — no policy could get it right. Markov = the state contains everything the future depends on.

Try

Set the velocity gap to 0. Now A and B are the same state — their futures coincide exactly. The physics is deterministic; all the "randomness" in CartPole comes from the start state and the policy.

The question Markov asks

If I freeze the world and show you only now, can you predict what happens next — as well as someone who watched the whole history?

One frame of Pong: no

A still ball could be going anywhere. Guessing is a coin flip. DeepMind's Atari agents fix this by feeding the network the last 4 frames as the state.

CartPole angle alone: no

A tilted pole might be falling or swinging back. That's why CartPole's state is 4 numbers, including the velocities. With them, the next moment is predictable.

The rule

If one snapshot isn't enough, put more into the state. A chat model's state is all the text so far — Markov by construction.
