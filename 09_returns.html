The done mask

Where done = 1, the G coming from the right is multiplied by 0: the next game's rewards can't leak into this one. Tick "show the bug" to see what happens without it.

Colour = Gt

Darker = more discounted reward still to come. The chart below follows the row you click: rewards are +1 every step, dones are the coral lines.

Watch the sweep

The loop fills one column at a time, right to left, for all 16 envs at once: G = r[:, i] + γ·G·(~done[:, i]).

The fade at the right edge

Envs still alive at step 149 start from G = 0, so their last steps look worthless — even though the pole is fine. That's the window cut-off. A critic (4 pm) would fill in V(s) there.

Tick "forget the mask"

G now flows across dones: the last steps of a dying game borrow the next game's reward and look good. Exactly the bug the quiz warned about.

4 envs · PolicyNetwork(4 → 120 → 84 → 2), freshly initialised like PyTorch

Follow one row

Each row is one env. obs goes through the network to 2 logits (any real numbers), log_softmax turns them into log-probabilities, multinomial samples an action, and gather picks the log-prob of that action (highlighted).

An untrained network is ~50/50

Fresh weights give logits near 0, so both actions are about equally likely. That's the policy VPG starts from — pure exploration.

Untick both boxes

With neither baseline nor normalisation every cell is teal: all returns are positive, so every action gets pushed up. With the baseline, roughly half flip to coral.

The chart: b(t) per column

The baseline is one number per timestep (shape (1, T)). It drops towards the right mainly because of the cut-off: near step 149 every Gt is small.

Top: which way each cell pushes

Each cell's gradient changes P(push right | that state) in proportion to adv · (one-hot(a) − π)right. teal = "push right more often here", purple = "push left more often here".

Bottom: the rule it's learning

Group every cell by its pole angle and add up the pushes. Leaning right (θ > 0) → net push toward right. Leaning left → toward left. Nobody told it — this came from +1 rewards and the baseline alone.

That's one gradient step

(iw · logprobs · adv).mean() → backward → Adam (maximize). Then this rollout is thrown away and a new one is played.
