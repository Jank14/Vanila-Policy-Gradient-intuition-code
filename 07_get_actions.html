TARA · RL week 1 · interactive 07

get_actions, with real numbers

obs → logits → log_softmax → sample → gather, for 4 envs at once.

Notebook
4 envs · PolicyNetwork(4 → 120 → 84 → 2), freshly initialised like PyTorch

Follow one row

Each row is one env. obs goes through the network to 2 logits (any real numbers), log_softmax turns them into log-probabilities, multinomial samples an action, and gather picks the log-prob of that action (highlighted).

An untrained network is ~50/50

Fresh weights give logits near 0, so both actions are about equally likely. That's the policy VPG starts from — pure exploration.

Click a row

The diagram on the left shows that env's hidden activations: 120 then 84 ReLU units (grey = 0, switched off), then the 2 logits — no ReLU at the end.

All 8 envs move together

One call to envs.step(actions) advances every env. Everything comes back with num_envs as the first dimension — one row per env.

Coral = done

That env's game ended on this step. It resets itself and keeps going in the same row, so one row holds several games.

Stored obs = before acting

add_step(obs, …) stores the observation the action was chosen from, then obs = new_obs moves on.

Edit anything

Type rewards, click done cells to toggle them, change γ. Then step the loop backwards and watch G carry from right to left.

The done mask

Where done = 1, the G coming from the right is multiplied by 0: the next game's rewards can't leak into this one. Tick "show the bug" to see what happens without it.
